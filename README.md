# Biosanity-1.20.X (WIP)
[![Join our Discord](https://img.shields.io/discord/1391884123722748026?label=Discord&logo=discord&style=flat&labelColor=7289DA&color=2ECC71&logoColor=white)](https://discord.gg/rJEKD3CQ8a)

Techno mod with bio elements for Minecraft 1.20.1 (may works on any 1.20.x, not tested yet).  
Written in Java 17.

### Version 0.1.x (current)
- UV lamp (repels undead mobs) and ways to obtain it
- Purification station with purifying and painting modes
- Neoplasm (wip) a block that is an uncommon enemy with special AI

### Planned
- Working A-life Neoplasm system
- New mobs and features
- Ways to resist neoplasm

### Installation
1. Install Minecraft 1.20.1 + Forge
2. Put the mod .jar file in your mods folder
3. Launch the game

For feedback, bugs and updates join our Discord.
